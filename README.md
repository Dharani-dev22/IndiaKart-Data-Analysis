# IndiaKart Data Analysis & Visualization Project

## Project Overview
This repository contains an end-to-end data analytics project for IndiaKart, a simulated e-commerce platform. The project spans the entire data pipeline, from raw data extraction and cleaning in Python to SQL database structuring and advanced visualization in Power BI. 

The primary objective of this analysis is to uncover actionable business insights, track key performance indicators (KPIs), and present sales trends to stakeholders through an interactive dashboard.

## Key Business Insights
* **Revenue Trends:** Total Average Order Value (AOV) remains stable at ₹63.20K, but overall Gross Merchandise Value (GMV) saw a significant decline in mid-2025.
* **Category Performance:** Electronics drive the highest overall revenue, while the Automotive category experiences the highest return rates.
* **Customer Demographics:** New customer acquisitions peaked sharply in early 2023. The 'Regular' segment dominates the user base at 40%, with the highest overall customer concentration in India.
* **Operations & Payments:** Delivery success remains high with over 32K completed orders. UPI is the leading payment method at 35.14%, while Shadowfax and XpressBees handle the highest volume of shipments.
* **Inventory Health:** Overall inventory health is strong with 92.2% of items in stock. However, immediate attention is required for low-stock items concentrated in the Hyderabad and Mumbai warehouses to prevent fulfillment delays.
